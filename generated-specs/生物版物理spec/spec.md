### ⚠️ 核心设计理念

> **生命结构、机制过程、参数实验和答题反馈是同一个生物场景的四个状态，不是四个独立模块的拼接。**

> 每一个知识点对应一个可视化生命机制场景，这个场景贯穿「讲解→探索→答题→反馈演示」四个阶段。学生始终在同一个细胞剖面、器官系统、遗传图谱、实验曲线或生态网络里学习和作答：讲解时场景展示结构与过程，探索时场景开放变量和图层，答题时场景锁定状态等待诊断，反馈时场景直接演示正确机制和常见误区。

> **如果把细胞剖面、器官系统、遗传图谱、生态网络、粒子流动、实验曲线和动态反馈去掉，只剩文字和选择题，这个产品就没有存在的价值。**

技术表现必须结合：
- **SVG**：细胞结构、细胞器、膜蛋白、器官系统、遗传图谱、实验曲线、生态网络、图例和交互热区——矢量精确，支持 CSS 动画、标注和状态切换
- **Canvas + JS**：扩散/渗透粒子、血流、神经脉冲、病原体扩散、生态种群、物质循环等连续动态过程——逐帧渲染，支持大量动态元素和实时参数响应
- **CSS 动画**：UI 过渡、显微扫描、荧光脉冲、结构高亮、标题页粒子——提升界面沉浸感

**禁止降级**：不可以用静态图片替代核心生物可视化，不可以用纯文字描述替代结构/机制判读，不可以跳过探索阶段的交互功能。

### 章节划分

> 章节按生命尺度或生物机制递进排列，从分子与细胞到器官系统，再到遗传、调节和生态综合。每章围绕一个生命主题展开，共 5-7 章，全书总计 20-25 题。

## 三、产品目的

### 核心价值

> **必须体现生物可视化核心**：核心价值中应包含「看见结构」「追踪过程」「调整变量」「观察反应」「理解结构如何产生功能」等关键词，而非「刷题」「背诵」「练习」。本产品是让学生用眼睛和手理解生命系统，不是电子版习题集。

### 成功标准

> 学生完成后，什么状态说明学习设计成功？（以机制理解、结构判读能力和成就解锁衡量，不以分数衡量）

- 能在细胞剖面、器官系统、遗传图谱、生态网络和实验曲线中找出关键信息
- 能解释至少一个生物因果链，例如“通道蛋白开放 → 粒子顺浓度梯度扩散 → 膜两侧浓度差变化”
- 能通过调参观察温度、pH、浓度、光照、心率、血氧、基因型、种群数量等变量如何改变结果
- 能把错误答案对应到真实常见误区，而不是只知道“错了”

## 四、视觉风格规范

> 本节强制约束游戏的视觉表现。生物游戏的视觉目标是「明亮生命图谱 + 动态显微工作台」：清晰、柔和、可判读，有层级感和结构感，细胞、组织、器官、曲线、图谱和粒子过程是视觉中心。

### 整体气质

**生命机制观察台感**：学生打开页面应该感觉站在一张可操作的生命科学观察台前，面前是细胞剖面、显微结构、器官系统、遗传图谱、实验曲线、生态网络和变量面板。不是课本截图，是「能动手观察机制」的互动生物场景。

### 背景系统

> 背景不是装饰，是氛围的基础。本项目使用全局固定背景图，所有 UI 和生物可视化浮在这张图之上。背景图必须由开发者在构建时编写提示词并调用生图模型生成。**禁止用 CSS 渐变、纯色或 SVG 冒充背景图。**

**背景图生成要求**：
- 提示词方向：**明亮专业生命科学图谱 / 显微观察工作台背景**——柔和细胞图谱、抽象显微视野、生命结构层级、实验观察台、半透明图谱面板，整体清晰、专业、无主体人物、无可读文字
- 参考关键词：`bright professional biology atlas workbench, microscope observation table, layered cell diagrams, translucent biological structures, soft fluorescence details, clean educational atmosphere, no people, no readable text, wide background composition`
- 如果无法调用生图模型，**必须停下来告知用户，不可用 CSS 替代**

**什么是"生图"**：
- ✅ 调用生图模型，输入提示词，获得一张真实的图像文件
- ❌ 用 CSS 渐变、box-shadow 画出来的图形 — 这不是生图
- ❌ 用 SVG path 手动描绘 — 这不是生图
- ❌ 用 Canvas 代码绘制 — 这不是生图

**实现要求**：
- `background-image` 固定铺满视口，`background-size: cover; background-position: center; background-attachment: fixed`

> 原则：背景图是固定的氛围底图，所有动态效果和注意力焦点在前景的生命结构、机制动画、参数控件和反馈演示上。背景不应分散对核心内容的注意力。

### 标题页图层层级原则

> 背景图必须永远位于所有 UI 内容之下，不得遮挡标题、按钮、结构缩略图、章节入口等任何前景元素。

- 推荐用 CSS `background-image` 属性实现背景图（作用于 body 或最外层容器），天然不会覆盖任何内容
- 如果用独立 div 实现背景图，必须确保该 div 不遮挡 UI——开发者自行选择最稳妥的实现方式
- 粒子 Canvas 不拦截 UI 点击事件

### 标题页氛围粒子（必须实现）

> 标题页必须有与生物主题匹配的氛围粒子效果，强化沉浸感。

- **粒子类型**：显微漂浮粒子、荧光点、分子扩散点、DNA 碱基短线、细胞扫描光点或生态种子粒子
- 粒子数量适中，不能像烟花或强特效
- 粒子在标题页全程可见；进入章节后可保留低密度版本作为氛围层，或关闭（不强制）
- 用 Canvas 或 CSS animation 实现均可，不影响性能
- 尊重 `prefers-reduced-motion`（关闭粒子运动，保留静态低透明纹理）

### UI 元素风格

> 所有 UI 元素走「清晰生命科学工作台」路线：清楚、可扫读、专业，有显微玻片和观察仪器感，但不浮夸。

- 标题和按钮可以有显微扫描线、细胞膜纹理、荧光边缘、轻微描边或 `text-shadow`
- 面板以浅色玻片、低透明灰白、淡青、低饱和草绿、浅蓝紫为主；荧光显微主题才使用深色半透明面板
- 按钮 hover 可以出现柔和荧光边缘或结构线条滑动
- 卡片圆角 4-8px，不做过大的胶囊按钮
- 图例、单位、比例、结构名和颜色编码必须清晰，不得为了风格模糊掉数据含义

### SVG/Canvas 可视化风格

> 生物可视化是本产品的核心，不是插图装饰。

**SVG 必须承担的内容**：

| 生物对象 | SVG 要求 |
|----------|----------|
| 细胞剖面 | 细胞膜、细胞核、线粒体、叶绿体、内质网、高尔基体、核糖体、液泡等分层清楚 |
| 细胞膜运输 | 通道蛋白、载体蛋白、主动运输泵、囊泡、浓度梯度、ATP 参与 |
| 分子机制 | 酶-底物结合、DNA → RNA → 蛋白质、信号通路、代谢路径 |
| 组织 / 器官系统 | 呼吸、循环、消化、神经、内分泌、泌尿、免疫等系统结构与流动 |
| 植物结构 | 叶片横切、气孔、维管束、根尖、花结构、蒸腾路径 |
| 遗传图谱 | Punnett 方格、染色体、基因位点、家系图、表型比例条 |
| 生态网络 | 食物链、食物网、能量金字塔、物质循环、种群曲线 |
| 实验图表 | 对照组、实验组、变量、曲线、数据点、误差范围 |
| 题目热区 | 结构点选、异常区域、拖拽锚点、诊断目标，必须有 hover/selected 状态 |

**SVG 质量硬约束**：
- 每个知识点至少有一个 SVG 或 SVG + Canvas 混合核心可视化
- 同一知识点四阶段共用同一可视化，通过 `vis_state` 切换状态
- 所有 SVG 图层需要有语义化分组，例如 `base-structure`、`organelle-layer`、`molecule-layer`、`flow-layer`、`labels-layer`、`interaction-layer`、`feedback-layer`
- 关键生命变量必须有可解释的视觉编码：颜色、线宽、透明度、粒子密度、流速、曲线高度、节点大小、箭头方向
- 结构图必须有图例，图例说明颜色/符号/单位，不得只靠用户猜
- 标注必须有避让策略，不遮挡关键结构、曲线、题目热区；必要时使用引线和锚点
- 动态标注平滑移动，不跳变
- 可交互对象必须有 hover、active、selected、locked、correct、incorrect 状态
- 结构简化必须服务教学，不能导致结构位置、功能或机制错误
- 手机端 SVG 必须可缩放、可平移或重排，核心标注不能被裁切

### 生物可视化原语速查

| 要画的东西 | 推荐技术 | 为什么 | 关键绘制点 |
|------------|----------|--------|------------|
| 细胞膜 / 双层膜 | SVG path + offset path + gradient + clipPath | 膜结构需要半透明、可开合、可承载通道蛋白 | 双层边界、膜内外区分、流动性纹理、通道嵌入膜上 |
| 细胞器 | SVG symbol/use + radialGradient + filter | 结构可复用，便于标注和状态高亮 | 核、线粒体、叶绿体等形态要可辨；不能全部画成普通圆 |
| 分子/离子粒子 | Canvas 粒子 + SVG 图例 | 数量多、需要随机运动和浓度变化 | 粒子大小/颜色区分物质；速度映射温度或浓度梯度 |
| 蛋白/酶结构 | SVG path + blob 形态 + active-site 标记 | 需要表达结合位点和构象变化 | 活性位点高亮；底物进入/离开路径清楚 |
| 跨膜运输 | SVG 通道/载体 + Canvas 粒子 | 骨架要精确，粒子要连续运动 | 通道开合、载体翻转、主动运输 ATP 消耗必须可见 |
| 血管/气体交换 | SVG 管腔 + clipPath + Canvas 血细胞流 | 需要血管结构和流体动态混合 | 红细胞沿管腔路径运动；氧气/二氧化碳粒子方向明确 |
| 神经元/突触 | SVG path + marker + 脉冲动画 | 神经纤维和信号方向需精确 | 动作电位沿轴突传播；突触递质释放和回收可见 |
| 遗传图谱 | SVG grid/tree + HTML/SVG 表格 | 方格、家系图、比例需要清晰排版 | Punnett 方格对齐；家系符号标准；比例条可读 |
| 生态网络 | SVG nodes/links + force-like layout / fixed layout | 节点、边、能量方向需要可点击 | 节点大小映射数量；箭头表达能量流方向；扰动后边/节点响应 |
| 实验曲线 | SVG axis + path + data points | 曲线判读依赖坐标、单位和趋势 | 自变量/因变量轴清楚；对照组和实验组线型区分 |
| 题目热区 | SVG transparent path + data-id + focus ring | 结构点选/异常诊断需要稳定命中区域 | 热区可略大于可见结构；hover 显示结构名；选中态不破坏原编码色 |
| 参数面板/图例 | HTML/CSS + SVG swatch | DOM 更适合读数、控件和图例 | 每种结构色、粒子、曲线、箭头都有标签和单位 |

#### 生物 SVG/CSS 质感配方

| 视觉对象 | 具体做法 |
|----------|----------|
| 细胞膜 | 用两条半透明曲线路径形成双层膜，中间夹低透明脂质纹理；膜边缘用柔和高光；膜内外区域通过浅色 tint 区分 |
| 细胞核 | `radialGradient` 形成球体感，核膜用双层描边，核仁用较深小圆；染色质可用低透明曲线纹理，不要把核画成纯色圆 |
| 线粒体 | 椭圆外膜 + 内部嵴状曲线；外膜用橙/红褐渐变，嵴用较亮细线；能量输出可用小 ATP 粒子从附近出现 |
| 叶绿体 | 椭圆体 + 类囊体堆叠短线/小圆盘；绿色渐变，光照时局部高亮；产物粒子从叶绿体流出 |
| 内质网/高尔基体 | 使用连续弯曲 path 或多层扁平囊状结构；边缘半透明；囊泡用小圆沿路径移动 |
| 通道蛋白 | 跨膜柱状或门型结构，开合用 transform scale/rotate；打开时粒子按浓度梯度穿过，关闭时粒子被挡住 |
| 载体蛋白 | 两态 path 或 group 切换，表现“朝外结合 → 翻转 → 朝内释放”；主动运输时同步显示 ATP 消耗 |
| 酶-底物 | 酶用不规则 blob path，活性位点用凹槽或高亮缺口；底物形状与位点互补；结合后有轻微吸附/锁定动画 |
| 血管与血流 | 管壁用双层 path，内腔用 clipPath；红细胞用扁椭圆，沿 path 移动时有轻微旋转；血氧高时红色更亮 |
| 神经信号 | 神经纤维用柔和紫蓝线，信号用黄色/白色脉冲沿 path 移动；突触处用粒子从突触前膜释放到突触后膜 |
| 抗体/病原体 | 病原体可用带刺外形但避免恐怖化；抗体用 Y 形 SVG symbol；结合时显示短暂锁定和高亮 |
| DNA/染色体 | DNA 用双螺旋曲线和横向碱基短线；染色体用 X 形或棒状结构，基因位点用小刻度标注；不得只作为背景装饰 |
| 食物网 | 节点用不同形状或颜色区分生产者/消费者/分解者；能量流用箭头线，线宽映射能量量级；扰动节点短时脉冲 |
| 实验曲线 | 对照组使用灰白或虚线，实验组使用主题高亮；数据点小圆可 hover 显示值；趋势变化用 path 插值 |

#### 生物动效模式

- **膜运输**：粒子按浓度梯度随机运动，通道开放时粒子穿过；主动运输粒子可逆浓度梯度移动，但必须同步显示 ATP 消耗。
- **渗透变化**：细胞轮廓通过 scale/path morph 缓慢膨胀或皱缩，水分子粒子方向与渗透压差一致。
- **酶促反应**：底物靠近活性位点、短暂停留、产物分离；温度/pH 改变时碰撞频率和酶构象稳定性同步变化。
- **光合作用**：光粒子进入叶绿体，CO2 和水进入，氧气/糖类产物粒子流出；光照强度改变时粒子密度连续变化。
- **血液循环**：红细胞沿血管 path 流动，血氧变化用红色明度和氧粒子数量表达；流速与心率参数联动。
- **神经传导**：电位脉冲沿轴突移动，突触处释放递质粒子；刺激频率升高时脉冲间距变短。
- **免疫清除**：免疫细胞追踪病原体，接触后吞噬或抗体结合；病原体数量曲线同步下降。
- **遗传推算**：Punnett 方格逐格填充，表型比例条平滑增长；不得用随机闪烁代替概率计算。
- **生态扰动**：某节点数量变化后，连接边亮度/宽度和相关种群曲线延迟响应，体现生态网络的连锁变化。
- **参数变化**：连续变量必须插值过渡，曲线、粒子密度、节点大小和数值读数同步更新。

#### 生物标注与图例原则

- 结构名称、功能、变量、单位必须贴近目标结构，并用细引线和小锚点连接。
- 标注不得遮挡膜通道、活性位点、突触、血管交换面、遗传比例、生态关键节点等判读位置。
- 多标注冲突时，优先保留题目相关标注，次要标注折叠为 hover 展开或侧栏列表。
- 图例必须解释结构颜色、粒子类型、箭头方向、曲线线型、节点大小、反馈色和单位。
- 数值和单位使用等宽字体，单位紧跟数值，例如 `37 °C`、`pH 7`、`90 mg/dL`、`75 bpm`。
- 答题阶段可以隐藏答案性标注，但不能隐藏完成判读所需的坐标轴、结构边界、图例、单位和题目条件。

#### 生物交互态视觉暗示

| 状态 | 视觉表现 |
|------|----------|
| hover 结构 | 结构外轮廓加亮，显示名称和功能 tooltip；不得把结构填成反馈色 |
| hover 粒子/路径 | 对应路径短时高亮，粒子速度略降便于观察，tooltip 显示物质名或信号名 |
| dragging 标注/节点 | 显示可吸附锚点、虚线辅助线和当前目标；错误锚点不强吸附 |
| adjusting 参数 | 相关结构、曲线和粒子实时响应，非相关图层降噪 |
| selected 结构 | 使用外环、角标或斜纹表示选择，不直接覆盖原结构色 |
| locked 答题态 | 非题目相关控件降 opacity，核心结构和必要图例保留；cursor 改为 default |
| correct | 反馈层短时绿色描边/路径高亮，并播放正确机制动画 |
| incorrect | 先用温和红色短时标出错误选择，再回到原结构色并演示正确机制 |
| disabled | 控件和图层开关降饱和，保留可读标签，不误导为未加载 |

#### 生物常见画错点

- 细胞膜不能画成普通实心圆；双层膜、内外环境和膜蛋白必须能区分。
- 细胞器不能无层级漂浮；位置、大小和与机制的关系必须服务知识点。
- 线粒体、叶绿体、细胞核不能只靠文字标注区分，形态特征必须可见。
- DNA 螺旋不能只做背景装饰；涉及遗传机制时必须参与信息流或位点标注。
- 主动运输不能画成顺浓度梯度的普通扩散；必须体现能量消耗或逆梯度。
- 酶失活不能画成酶“消失”；应表现构象改变或活性位点失配。
- 血氧、炎症、突变、错误反馈不能全部用同一种红色表达。
- 遗传概率不能用随机动画代替；比例必须由基因型规则计算并可解释。
- 食物网箭头方向必须表达能量流方向，不能画成随意关系线。
- Canvas 粒子不得遮挡结构名、曲线轴、题目热区和关键图例。
- 答题反馈不能永久改写结构原始编码色，否则会破坏后续判读。

#### Canvas 适用范围

Canvas 用于大量粒子或连续场变化：

- 分子随机运动、扩散、渗透。
- 红细胞流动、氧气/二氧化碳运输。
- 神经信号传播、电位波。
- 病原体扩散、免疫细胞追踪和吞噬。
- 生态种群粒子、能量流、物质循环。
- 花粉传播、种子扩散、细胞分裂动画。

SVG 与 Canvas 可以混用：SVG 负责结构、路径、标注、坐标、图例和交互热区；Canvas 负责粒子、流动、扩散和连续动态。

### 配色方案

> 配色必须先服务生物编码，其次才服务氛围。颜色不能只是好看，必须能被图例解释。

**UI 基础色**：
- 背景/表面：雾白、玻片白、浅灰、淡青、浅蓝紫、低饱和草绿
- 面板分隔：低透明冷灰、玻片灰、低饱和青灰、浅紫灰
- 文字/标注：深墨绿、炭灰、显微黑、冷白、浅暖白
- 交互强调：青蓝、荧光绿、琥珀、玫红、浅紫、叶绿、氧合红
- 正确/错误：清晰绿色 / 温和红色，仅用于反馈层，不永久改变原结构色彩

**生物专题色板**：
- 细胞结构：细胞膜青绿、细胞核蓝紫、线粒体橙红、叶绿体绿色、内质网浅紫、高尔基体粉橙
- 分子与运输：水分子浅蓝、氧气淡青、二氧化碳灰蓝、葡萄糖琥珀、ATP 金黄、离子蓝/紫
- 植物生理：叶绿、气孔青、导管蓝、筛管橙、光照暖黄
- 人体系统：血氧亮红、静脉蓝紫、神经黄白、激素粉紫、免疫青绿
- 遗传：DNA 蓝紫、RNA 青、蛋白质橙、显性/隐性使用可解释且非红绿唯一编码
- 生态：生产者绿、消费者琥珀、分解者褐紫、能量流金黄、物质循环蓝绿

### 排版规范

- 标题字体要有生物主题感，但不能牺牲可读性
- 主标题字号 ≥ 40px（移动端）/ ≥ 56px（桌面端）
- 副标题字号约为主标题的 40-50%，字重轻，体现层次
- 结构标注、图例、单位、题干必须清晰，正文最小字号不低于 14px
- 数值和单位建议使用等宽字体，例如 `37 °C`、`pH 7`、`90 mg/dL`、`75 bpm`

### 间距与圆角

- 工具面板、图例、题目区域间距保持 12-20px
- 卡片圆角 4-8px
- 可视化区域需要稳定尺寸，不能因题目或反馈文字变化而跳动
- 移动端参数面板可折叠，但不得遮挡核心结构和关键标注

### 动效标准

- **标题页进场**：背景图淡入 → 显微/荧光粒子开始 → 主标题上浮淡入 → 副标题淡入 → 按钮淡入，依次触发，总时长 ≤ 1.5s
- **标题页按钮**：常态有轻微呼吸脉动，hover 轻微上浮或描边发亮，click 短暂按压
- **标题页 → 章节主页**：显微扫描线或荧光结构光带扫过，内容淡出淡入，不瞬切（500-800ms）
- **章节过渡**：1.5-3s，可使用显微聚焦、结构放大、荧光路径点亮、DNA 片段展开
- **参数变化**：温度、pH、浓度、光照、心率、血氧、种群等连续变量必须插值过渡，图例读数同步平滑变化
- **反馈演示**：先呈现用户选择的结果，再演示正确机制，过程要可暂停或重播
- 动效必须服务理解、反馈或氛围，不允许无意义闪烁
- `prefers-reduced-motion` 下关闭装饰性动画，保留核心生物过程演示的必要版本

### 游戏界面布局

| 页面 | 核心元素 | 操作 |
|------|----------|------|
| 标题页 | 游戏名称（主题化字体特效）+ 副标题 + AI 生成生物背景图 + 开始/继续按钮 + 氛围粒子 | 点击按钮 |

| 结局总结 | 成就墙、各章回顾、鼓励文案 | 回看或重开 |

### 标题页设计规范

标题页必须是独立完整入口，不得把章节、题目或学习内容直接铺在标题页下方。

标题页必须包含：
- AI 生成背景图
- 主标题
- 副标题 / 一句生命科学引言
- 开始学习按钮
- 如果有存档，显示继续学习按钮
- 低密度生物氛围粒子

标题样式：
- 主标题字号 ≥ 40px（移动端）/ ≥ 56px（桌面端），有生物主题字体特效（显微扫描纹理、细胞膜纹理、DNA 切线、柔和荧光描边或亮色填充）。标题基色必须可见，特效是增强而非前提
- 副标题不超过 1-2 行，避免长段说明
- 按钮必须清楚可点击，hover/active 状态明显

进场顺序：
1. 背景图淡入
2. 显微/荧光粒子开始漂浮或扫描
3. 主标题上浮淡入
4. 副标题淡入
5. 按钮淡入

**按钮动效**：
- hover：轻微上浮 + 柔和描边或荧光边缘
- active：短暂按压
- 不允许按钮无反馈

**标题页 → 章节主页过渡**：点击按钮后，标题页内容淡出，可加显微扫描线、结构光带或 DNA 片段汇聚效果（500-800ms），背景图保持不动

## 九、交互设计

### 交互模式选择

**本项目选择**：新手友好 + 生物探索式

**选择原因**：目标用户是学生，基本操作（点击推进 + 选择答案）要极简，但探索阶段需要滑块、图层开关、结构点选、标注拖拽、时间轴等交互来建立生命结构感和机制直觉。

### 操作映射

| 行为 | 操作 | 反馈 |
|------|------|------|
| 推进讲解 | 点击"继续"按钮 | 文字和生物动画同步，按钮在动画播完后出现 |
| 交互探索 | 拖拽结构点/调节滑块/切换图层/拖拽标注 | 可视化实时响应，数值面板同步更新 |
| 回答问题 | 点击选项、点选结构、拖拽标注、排序或匹配 | 提交后进入反馈演示，答错可重试 |
| 查看反馈 | 点击"继续"或"重试" | 进入下一知识点或返回答题 |
| 回看章节 | 点击已完成章节 | 进入只读回看，不重置首次答案 |
| 读档 | 点击标题页"继续学习" | 进入章节主页，恢复存档进度 |

### 交互探索的具体模式

> 探索阶段的交互方式取决于生物内容，以下为常见模式：

| 模式 | 适用内容 | 操作 |
|------|----------|------|
| 滑块调参 | 温度、pH、浓度、光照、心率、血糖、种群数量等连续变量 | 拖拽滑块，结构/曲线/粒子实时更新 |
| 图层开关 | 细胞器、分子、信号、血流、基因型、生态营养级等图层 | 点击 toggle 或标签页显示/隐藏图层 |

| 拖拽标注 | 结构名称、功能、流程箭头、基因型/表型标签 | 拖到锚点或图谱位置 |
| 过程排序 | 酶促反应、膜运输、神经传导、免疫应答、蛋白合成 | 拖拽阶段卡片排序 |
| 机制匹配 | 结构 ↔ 功能、变量 ↔ 结果、现象 ↔ 原因 | 点击或拖拽连线 |

| 遗传推算 | Punnett 方格、家系图、比例条 | 填格、选择基因型/表型比例 |
| 播放/暂停 | 生物过程模拟 | 点击播放按钮，可暂停在任意时刻观察 |

| 状态 | 反馈 | 状态变化 |

| 拖拽参数 | 可视化实时变化 + 数值更新 | 无状态变化 |
| 切换图层 | 图层淡入/淡出，图例同步更新 | 无状态变化 |
| 答对 | 正确结构/路径高亮，关键机制播放，成功色反馈 | 可能触发成就 |
| 答错 | 错误选择短暂标出，然后播放正确机制和误区解释 | 可重试，首次答案保留 |

## 十、核心机制约束

### 生物准确性（极其重要）

- 结构名称、位置、功能关系必须正确——**这是本产品的底线**
- 细胞膜运输、酶促反应、光合作用、呼吸循环、神经传导、免疫应答、遗传推算、生态网络等机制必须符合生物学规律
- 实验变量、自变量/因变量、对照组、单位、曲线趋势必须正确
- 遗传比例、Punnett 方格、家系图判断不能使用随机结果代替规则计算
- 探索阶段的参数范围必须生物上合理

### 知识自检规则

> **AI 在生成内容时，必须对所有涉及的生物知识执行自检。** 这是强制流程，不可跳过。

每个知识点生成后必须检查：
1. **结构验证**：本章出现的结构、器官、细胞器、分子或生态节点是否正确？
2. **机制验证**：运输、代谢、调节、遗传、生态等过程是否符合生物规律？
3. **实验验证**：曲线、对照组、变量、单位、结论是否清楚且正确？
4. **题目验证**：题目答案是否唯一或规则明确？错误选项是否是合理误区？
5. **可视化一致性**：可视化中的变化是否与机制一致？例如主动运输需要能量消耗，光照增强使光合速率在限制范围内变化，病原体下降应对应免疫清除过程

### 知识点四阶段闭环规则

> **这是本游戏区别于普通题库的核心机制。** 每个知识点必须走完四个阶段，且四个阶段共用同一个生物可视化。

#### 1. 讲解阶段

- 一边说结构/机制一边播放细胞、器官、图谱、曲线或生态网络动画，学生看到生物过程
- 文字短，每次 1-2 句
- 出现关键结构标注和图例
- 不出题

#### 2. 探索阶段

- 开放交互参数，学生自己拖拽/调节/切换图层
- 必须有至少一个参数会改变可视化
- 可视化实时响应参数变化，数值面板和图例同步更新
- 不要求学生答对，只让学生观察

#### 3. 答题阶段

- **题目必须基于前两个阶段的可视化出题**，考察学生对结构、图谱、曲线和生物过程的理解
- 可视化锁定在特定状态，或隐藏部分答案性标注
- 题型可以是 3 选 1、结构点选、拖拽标注、机制匹配、过程排序、曲线判读、遗传推算、生态网络预测、异常诊断
- 答案提交后不能直接只显示文字

#### 4. 反馈演示

- **不管答对还是答错，都用同一可视化演示**
- 答对：播放正确机制路径
- 答错：先展示错误选择会导致的机制问题，再播放正确过程
- 语气鼓励："没关系，我们看看这个结构和变量会怎样变化" 而不是 "错了"

### 四阶段的可视化一致性

- **禁止**每个阶段造一个不相关的图——四个阶段是同一个细胞/器官/图谱/曲线/生态网络场景的不同状态
- 讲解时：可视化处于「演示模式」，按预设流程播放
- 探索时：可视化处于「交互模式」，参数和图层开放
- 答题时：可视化处于「锁定模式」，特定参数固定或部分标注隐藏
- 反馈时：可视化处于「演示模式」，播放答案对应的过程

### 成就系统规则

每章固定 3 个成就：

| 类型 | 触发条件 | 生物风格 |
|------|----------|----------|
| 全对成就 | 本章所有题首次答对 | "机制观察家"类称号 |
| 全错成就 | 本章所有题首次答错但完成重试 | "误区清除者"类称号 |
| 创意成就 | 探索阶段触发特殊参数组合或隐藏观察 | "生命变量调试师"类称号 |

规则：
- 成就只基于首次答题结果
- 重试不改变首次答题记录
- 全错成就不是惩罚，文案必须鼓励
- 创意成就由生物内容决定，例如把温度/pH 调到极端但合理范围，触发酶活性异常提示
- 不显示总分、不显示百分比、不做排行榜

### 章末知识总结

每章完成后展示：
- 本章 3-4 个核心机制
- 关键结构/图谱/曲线回顾
- 常见误区
- 已解锁成就
- 下一章预告

### 结局总结

全章完成后展示：
- 成就墙
- 各章核心结构与机制回顾
- 鼓励语
- 返回章节主页 / 重新开始

### 生物场景速查

#### 分子与生化
- 酶促反应：酶-底物结合、活性位点、温度/pH 对速率影响
- 扩散与渗透：浓度梯度、半透膜、水分子移动、细胞体积变化
- 代谢路径：反应物、中间产物、ATP、反馈抑制

#### 细胞结构
- 动植物细胞对比：细胞壁、叶绿体、液泡、中心体等差异
- 细胞器协同：核糖体、内质网、高尔基体、囊泡、细胞膜分泌路径
- 跨膜运输：自由扩散、协助扩散、主动运输、胞吞胞吐

#### 植物生理
- 光合作用：光照、CO2、水分、叶绿体、产氧量、糖类生成
- 蒸腾作用：气孔开度、温度、湿度、运输路径
- 维管束运输：导管、筛管、水分与有机物方向

#### 人体系统与稳态
- 呼吸与循环：肺泡气体交换、血红蛋白、血氧变化
- 血糖调节：胰岛素、胰高血糖素、负反馈曲线
- 体温调节：产热、散热、汗腺、血管舒缩
- 消化吸收：酶、营养物质、吸收路径

#### 神经与免疫
- 神经传导：动作电位、突触、递质、兴奋/抑制
- 免疫应答：病原体识别、吞噬、抗体、记忆细胞
- 疫苗原理：抗原呈递、免疫记忆、二次应答曲线

#### 遗传与发育
- Punnett 方格：亲本基因型、子代表型比例
- 家系图：显性/隐性、伴性遗传、携带者判断
- DNA 表达：转录、翻译、蛋白质合成
- 突变：碱基变化、蛋白质影响、表型变化

#### 生态系统
- 食物链/食物网：生产者、消费者、分解者
- 能量流：能量逐级递减、生态金字塔
- 物质循环：碳循环、氮循环、水循环
- 种群变化：捕食-被捕食、资源限制、环境扰动

### 关键生物规律与知识点

- 结构与功能相适应，结构变化会影响机制结果
- 扩散和渗透受浓度梯度、膜通透性和环境条件影响
- 酶活性受温度、pH、底物浓度等因素影响，极端条件可能改变构象
- 稳态调节常通过负反馈维持变量在合理范围
- 遗传比例必须来自基因型规则，不可用随机动画代替
- 生态网络中一个节点变化会影响相关种群、能量流和物质循环

- 每章 3-4 个知识点
- 每个知识点 1 个核心可视化
- 每个知识点 1 道核心题
- 每章 3 个成就
- 全书 20-25 题

## 十二、技术约束

| 维度 | 约束 |
|------|------|
| 技术栈 | 单文件 HTML + CSS + JavaScript + 内嵌 SVG/Canvas |
| 部署方式 | 静态文件，可直接打开 |
| 外部依赖 | 默认零依赖；如使用字体 CDN 必须有 fallback |
| 进度缓存 | localStorage |
| 性能 | 首屏 UI < 2s；核心动画 ≥ 30fps；SVG 操作不卡顿 |
| 响应式 | 桌面、平板、手机可用；移动端核心可视化可缩放 |
| 无障碍 | 键盘可操作主要按钮；颜色编码配合文字/图例；减少动画模式可用 |

### SVG 性能约束

- 复杂结构图应合理分层，避免单个 SVG 节点过多导致卡顿。
- 动态变化优先更新 transform、opacity、stroke-dashoffset、path 参数或少量数据点，不要全量重建 DOM。
- 大量粒子使用 Canvas，不用数百个 SVG circle 硬撑。
- 图层开关应改变 group 可见性，避免销毁重建。
- 移动端可降低非核心粒子密度，但不得删除核心结构信息。
- 参数变化时优先更新必要 path、transform、opacity、stroke、fill 或 Canvas 粒子状态，不得每次重建整棵可视化 DOM。

## 十三、开发指引

收到本 spec.md 后：
1. 进入 plan 模式，按章节拆分开发任务
2. 每个任务读取对应的 SKILL 文件，提取具体生命结构、功能关系、机制过程、生物规则、实验变量、数据、题目依据和可验证结论
3. 为背景图编写生物主题提示词并调用生图模型生成；如无法生图必须停下来告知用户，不可用 CSS 替代
4. 实现标题页（AI 背景图 + 进场动画 + 粒子 + 生物主题字体 + 按钮动效）
5. 实现全局 UI 框架（玻片面板 / 图例 / 参数控件 / 清晰按钮 / 响应式布局）
6. 实现章节主页（所有章节解锁状态、当前章节高亮、已完成可回看、未解锁锁定）
7. 逐章实现知识点的四阶段闭环（讲解→探索→答题→反馈），每个知识点一个生物可视化
8. 实现成就系统（每章 3 个成就：全对/全错/创意）
9. 遵守「核心机制约束」中的所有规则
10. 执行「知识自检」——逐章核对结构、机制、实验、遗传、生态、单位和答案的正确性
11. 对 SVG/CSS 绘制指南执行专项自检，确认生物可视化原语、质感配方、动效模式、标注/图例、交互态、常见画错点均已落实
12. 完成后执行全量自检（对照验收标准）
